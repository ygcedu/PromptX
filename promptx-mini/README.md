# 🚀 PromptX Mini - 核心理念极简实现

> 用300行代码展示PromptX的核心魔法：AI角色化 + 记忆系统 + 工具集成

## 🎯 核心概念演示

这个极简版本展示了PromptX的四大核心理念：

### 1. 🧠 认知记忆系统
- **概念节点**: 存储知识概念
- **连接关系**: 建立概念间的关联
- **激活传播**: 智能检索相关知识
- **记忆强化**: 根据使用频率调整权重

### 2. 🎭 角色专业化系统  
- **内置角色**: 产品经理、架构师、内容专家
- **专业知识**: 每个角色有独特的知识体系
- **行为模式**: 不同角色有不同的思考方式
- **角色切换**: 瞬间获得专业能力

### 3. 🔧 工具集成系统
- **工具注册**: 动态添加新工具
- **智能调用**: 根据意图自动选择工具
- **结果处理**: 统一的工具执行框架
- **使用统计**: 跟踪工具使用情况

### 4. 💬 自然语言交互
- **意图识别**: 理解用户真实意图
- **上下文管理**: 保持对话连贯性
- **智能响应**: 结合角色和工具的综合回答

## 🎭 内置角色详解

### 产品经理 (product-manager)
- **专业领域**: 用户体验、敏捷开发、数据分析、竞品分析、MVP设计
- **思维方式**: 结构化思考，用户导向
- **适用场景**: 产品设计、用户研究、需求分析

### 架构师 (architect)  
- **专业领域**: 微服务架构、分布式系统、性能优化、安全设计、云原生
- **思维方式**: 技术深度，全局视角
- **适用场景**: 系统设计、技术选型、架构优化

### 内容专家 (writer)
- **专业领域**: 内容营销、SEO优化、用户心理学、品牌传播、多媒体制作
- **思维方式**: 创意思维，情感共鸣  
- **适用场景**: 文案写作、内容策略、品牌传播

## 🔧 内置工具详解

### 计算器 (calculator)
- **功能**: 执行数学表达式计算
- **用法**: `计算 2+3*4`
- **支持**: 基本四则运算、括号、小数

### 文本分析器 (text-analyzer)
- **功能**: 分析文本统计信息
- **用法**: `分析文本: 你的文本内容`
- **输出**: 字符数、词数、句子数、阅读时间

### 数据存储 (data-store)
- **功能**: 键值对数据存储和检索
- **用法**: `存储数据` 或 `获取数据`
- **特点**: 与记忆系统集成

## 🎨 扩展开发

### 添加新角色
```javascript
// 在 role.js 中添加
this.defineRole('data-scientist', {
  name: '数据科学家',
  description: '专业的数据分析和机器学习专家',
  knowledge: [
    '统计学原理',
    '机器学习算法', 
    '数据可视化',
    'Python/R编程',
    '业务洞察分析'
  ],
  behavior: {
    style: '数据驱动，逻辑严谨',
    approach: '用数据说话，从统计角度分析问题',
    tools: ['数据分析', '模型训练', '可视化']
  }
})
```

### 添加新工具
```javascript
// 在 tool.js 中添加
this.registerTool('weather', {
  name: '天气查询',
  description: '查询指定城市的天气信息',
  parameters: ['city'],
  execute: (city) => {
    // 实现天气查询逻辑
    return { 
      success: true, 
      weather: `${city}今天晴天，25°C` 
    }
  }
})
```
