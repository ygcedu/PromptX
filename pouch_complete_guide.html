🎯 PromptX Pouch 框架概览

🧠 核心理念

PromptX Pouch 框架实现了"诸葛锦囊"的设计模式，基于 PATEOAS (Prompt as the Engine of Application State) 理念， 每个锦囊都是自包含的专家知识单元，通过状态驱动的导航系统实现AI工作流程的智能串联。

🏗️ 核心组件

  • BasePouchCommand - 锦囊基类
  • Purpose - 锦囊目的说明
  • Content - 锦囊核心内容
  • PATEOAS - 导航信息
  • StateContext - 状态上下文

🎨 渲染架构

  • Areas - 内容区域（兼容模式）
  • Layers - 认知层次（新架构）
  • Renderer - 渲染管道
  • Formatter - 输出格式化

📋 锦囊输出格式 (PouchOutput)

每个锦囊都遵循统一的三层输出结构，确保AI能够理解和使用：

🎯 Purpose (目的)

说明锦囊的作用和使用场景，让AI明确当前锦囊的功能定位。

📝 Content (内容)

锦囊的核心内容，包括提示词、知识、指令等，是锦囊的主体部分。

🧭 PATEOAS (导航)

下一步可执行的动作列表，实现状态驱动的导航系统。

🏗️ 框架架构层次

🚀 CLI 入口层 (Entry Layer) 核心接口

PouchCLI

CLI主入口，提供命令行接口和统一的执行入口。负责初始化、命令解析和交互式模式。

index.js

框架导出模块，提供便捷的API接口，包括execute()、help()、status()等方法。

📋 注册管理层 (Registry Layer) 命令管理

PouchRegistry

锦囊命令注册器，负责管理和注册所有锦囊命令，提供命令验证和查询功能。

🔄 状态管理层 (State Layer) 状态转换

PouchStateMachine

状态机管理器，负责管理锦囊之间的状态转换，维护历史记录和上下文信息。

⚡ 命令执行层 (Command Layer) 业务逻辑

BasePouchCommand

命令基类，支持Layer和Area双架构，提供统一的渲染管道和执行流程。

ProjectCommand
项目初始化和管理
DiscoverCommand
发现可用角色和工具
ActionCommand
角色激活和状态管理
LearnCommand
领域知识学习
RecallCommand
记忆检索和回忆
RememberCommand
记忆存储和管理
ThinkCommand
思维过程和推理
ToolCommand
工具执行和管理
🧩 Areas 实现层 (Implementation Layer) 具体实现

BaseArea

Area架构的抽象基类，定义了单一职责的内容块渲染接口。

CognitionArea

认知处理区域，负责思维和推理相关的内容渲染。

RoleArea

角色相关区域，处理角色激活和状态展示。

StateArea

状态管理区域，显示当前状态和可用转换。

LegacyArea

兼容性区域，包装旧的getPurpose/getContent方法。

🏗️ 双架构渲染系统

🆕 Layer 架构 (新)

三层认知架构，提供更高层次的组织和协调：

ConsciousnessLayer
意识层
CognitionLayer
认知层
RoleLayer
角色层

特点：Layer包含多个Area，支持复杂的认知处理流程。

🔄 Area 架构 (兼容)

直接的Area渲染，保持向后兼容：

BaseArea
基础区域
具体Area实现
如RoleArea、StateArea
LegacyArea
兼容包装

特点：单一职责，适合简单场景，兼容旧命令。

📦 项目中的8个锦囊

🏗️

ProjectCommand

project
项目管理锦囊，负责项目初始化、环境配置和状态管理。支持多IDE环境检测和项目资源目录创建。
  • 项目路径验证和初始化
  • IDE类型自动检测
  • .promptx目录结构创建
  • 项目配置文件生成
  • 资源管理器刷新
🔍

DiscoverCommand

discover
资源发现锦囊，展示所有可用的AI角色和工具。按来源分类显示系统级、项目级和用户级资源。
  • 角色资源发现和分类
  • 工具资源发现和分类
  • 注册表自动刷新
  • 统计信息展示
  • 资源来源标识
🎭

ActionCommand

action
角色激活锦囊，专注于角色激活和提示词展示。使用新的Layer架构渲染角色的完整语义信息。
  • 角色语义解析和渲染
  • 人格特征展示
  • 行为原则加载
  • 专业知识激活
  • 依赖资源分析
📚

LearnCommand

learn
领域学习锦囊，帮助AI学习特定领域的知识和技能。支持知识资源的加载和整合。
  • 领域知识加载
  • 学习路径规划
  • 知识结构化展示
  • 学习进度跟踪
  • 知识依赖分析
🧠

RecallCommand

recall
记忆检索锦囊，基于认知体系进行智能语义检索。支持DMN模式和关键词检索两种模式。
  • 语义网络激活
  • DMN全景扫描
  • 关键词精确检索
  • 记忆网络图展示
  • 认知模式切换
💾

RememberCommand

remember
记忆保存锦囊，基于认知体系保存角色专属记忆。支持批量Engram保存和记忆网络更新。
  • Engram批量保存
  • 记忆强度设置
  • 记忆类型分类
  • 语义网络更新
  • 记忆验证机制
🤔

ThinkCommand

think
思考锦囊，基于认知心理学的思维链式推理。支持多种思维模式和递归深化的思考过程。
  • 思维模式选择
  • 目标导向推理
  • 洞察生成机制
  • 结论形成过程
  • 置信度评估
🔧

ToolCommand

toolx
工具执行锦囊，实现ToolX系统的工具执行功能。支持多种执行模式和沙箱环境管理。
  • 工具沙箱执行
  • 多模式支持
  • 依赖自动管理
  • 手册自动生成
  • 环境变量配置

🌟 锦囊核心特性

🎯 自包含设计

每个锦囊都是独立的专家知识单元，不依赖外部上下文，可以独立执行。

🧭 PATEOAS导航

每个锦囊都提供下一步操作指引，实现状态驱动的智能导航系统。

🏗️ 双架构支持

同时支持Layer和Area两种架构，新旧系统并存，保证向后兼容。

🤖 AI友好

专为AI使用优化的接口设计，支持JSON和人类可读两种输出格式。

🔄 状态管理

自动记录状态历史，持久化到配置文件，支持状态回溯和恢复。

🧠 认知集成

深度集成认知管理系统，支持记忆检索、保存和思维推理。
